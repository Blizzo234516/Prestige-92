# Prestige 92







Prestige 92 is a RuneLite plugin that adds a virtual prestige progression system for skills after level 92.



In Old School RuneScape, level 92 is approximately halfway to level 99 in terms of experience. Prestige 92 makes the second half of the journey feel like levelling from 1 to 92 again.



#### \## How it works



When a skill reaches level 92, Prestige 92 begins tracking a virtual Prestige level for that skill.



Your progress from real level 92 to 99 is mapped across Prestige levels 1 to 92.



For example:



\- Real level 92 = beginning of the Prestige journey

\- Progress towards level 99 = progress through Prestige levels

\- Real level 99 = Prestige level 92 complete



Prestige levels are purely visual and do not affect your actual Old School RuneScape levels or experience.



#### \## Features



\- Supports all RuneLite skills automatically

\- Dedicated RuneLite sidebar tracker

\- Prestige progress bars for individual skills

\- Displays real XP required for the next Prestige level

\- Hover tooltips with detailed XP information

\- Customisable progress bar colours

\- Prestige level-up notifications

\- Optional level-up sound

\- Optional fireworks animation

\- Optional chat messages

\- Special completion state when reaching level 99

\- Progress is calculated from your real RuneScape XP, so no Prestige progress is lost between sessions



#### \## Privacy



Prestige 92 does not collect or transmit any personal data.



All settings are stored locally using RuneLite's configuration system.
